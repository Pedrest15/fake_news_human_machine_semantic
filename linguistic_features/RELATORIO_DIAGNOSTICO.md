# Relatório de Diagnóstico — Features Essenciais para o Desempenho do Classificador

## 1. Configuração do experimento

O diagnóstico foi executado por [linguistic_features/feature_diagnostic.py](feature_diagnostic.py) sobre **839 features linguísticas** — 184 NILC-Metrix (após o blacklist Tier A de contagens absolutas), 76 LIWC, 500 regras Enhanced UD (top-K), 60 termos SAGE, 17 contagens POS, 2 estatísticas de sílabas e zero features de `parser_stats` (loader retornou vazio). Os embeddings BERT (768 dimensões) foram deliberadamente excluídos do escopo. Os splits efetivamente carregados são **8 250 documentos de treino e 2 052 de teste** — observe que esses números são maiores que os 5 758 / 1 439 do run `combined` anterior, justamente porque o caminho linguístico não exige que o documento esteja presente no cache de embeddings BERT, então cerca de 95 % dos pares pareados sobrevivem ao `inner join` entre os grupos.

Para cada feature foram computadas quatro métricas: a **informação mútua** com o rótulo (estimador k-NN de `mutual_info_classif`, `random_state=42`); o **F-statistic da ANOVA univariada** (`f_classif`); a **correlação de Pearson sinalizada** com o rótulo; e o **F1 ponderado no conjunto de teste** atingido por uma regressão logística L2 treinada usando apenas aquela feature como input. Em seguida, ordenando as features pelo F1 univariado decrescente, fez-se uma **busca incremental** treinando um SVM linear (`C=0,1`, mesmo do run que produziu o F1 = 1,0 inicial) sobre os top-1, top-2, top-3 … top-839 features, registrando a curva F1 vs. k e procurando o menor k tal que F1 ≥ 0,9999.

## 2. O achado central: o sinal linguístico tem teto em F1 ≈ 0,995

A busca forward **falhou em encontrar k tal que F1 ≥ 0,9999**: usando apenas features linguísticas, o classificador SVM linear nunca atinge perfeição no teste. O ápice da curva ocorre em **k = 75 com F1 = 0,9946**, e a partir desse ponto o desempenho **oscila para baixo** (k = 100 → 0,9937; k = 150 → 0,9917; k = 200 → 0,9917; k = 300 → 0,9932; k = 600 → 0,9917). Esse comportamento — saturação seguida de leve degradação — é o sintoma clássico de features adicionais que injetam ruído mais do que sinal: depois das 75 melhores, cada feature extra contribui mais variância que poder discriminativo. Com todas as 839 features, o SVM linear ficaria abaixo do pico atingido com 75.

Esse achado **reposiciona a interpretação dos resultados anteriores**. O F1 = 1,0000 reportado no `combined_svm.json` e `combined_logistic_regression.json` **depende necessariamente dos 768 embeddings do BERTimbau** — eles fornecem o último 0,5 % de F1 que o conjunto linguístico isoladamente é incapaz de atingir. Isso contradiz minha leitura anterior em [RELATORIO_RESULTADOS.md §3](RELATORIO_RESULTADOS.md), em que sugeri que "o classificador não está usando os embeddings do BERTimbau de maneira significativa" baseado em uma única dimensão BERT no top-10. Olhando agora pela ótica do conjunto mínimo suficiente, a contribuição do BERT é qualitativa: o sinal linguístico carrega o classificador de 0 a 99,5 % de F1, e o BERT carrega o "último centímetro" que o leva exatamente a 100 %. Ambos os componentes são, portanto, **essenciais**, ainda que de forma assimétrica.

## 3. As features linguísticas mais informativas

Os três rankings — informação mútua, F-statistic ANOVA e F1 univariado — convergem em larga medida, com diferenças informativas. O **MI** elege como #1 a feature `nilc__sentences_per_paragraph` (MI = 0,520), seguida de `nilc__lsa_all_std` (0,442), `nilc__lsa_paragraph_mean` (0,375), `syll__media_silabas_por_palavra` (0,347) e `nilc__flesch` (0,333). A **F-statistic ANOVA** reordena o topo dando primazia à complexidade lexical: `syll__media_silabas_por_palavra` (F = 7 521), `nilc__flesch` (F = 7 198), `nilc__syllables_per_content_word` (F = 6 778), `nilc__idade_aquisicao_mean` (F = 5 312), `nilc__honore` (F = 4 811). E o **F1 univariado no teste** — a métrica mais decisiva, porque diz quanto cada feature "vale" sozinha — encabeça com `syll__media_silabas_por_palavra` (F1 = 0,8404), `nilc__flesch` (0,8337), `nilc__syllables_per_content_word` (0,8302), `nilc__honore` (0,8185) e `nilc__content_word_diversity` (0,8152).

Há uma divergência interessante entre MI e F-statistic. O MI captura dependência **não-linear** ponto-a-ponto, enquanto a F-statistic mede a razão entre variância intergrupos e variância intragrupos, assumindo linearidade. O fato de `nilc__sentences_per_paragraph` liderar em MI mas não estar no top-5 da F-stat sugere que sua relação com o rótulo é **não monotônica** — provavelmente bimodal ou em platô. Já `syll__media_silabas_por_palavra` lidera em F-stat e F1 univariado mas é #4 em MI, indicando uma relação linear forte porém quase saturada: a F-stat se beneficia da separação clara das médias, mas o MI captura redundância com outras features. Para o paper, vale citar as três métricas em paralelo na tabela, porque cada uma destaca um aspecto diferente do sinal.

## 4. Quanto cada feature sozinha já consegue

O **F1 univariado é o achado mais didático** para construir a argumentação no paper. Uma única feature — `syll__media_silabas_por_palavra` (média de sílabas por palavra) — atinge sozinha F1 = 0,8404 e accuracy = 0,8445 no conjunto de teste held-out. Isso é apenas 11 pontos percentuais abaixo do limite superior atingido com 75 features e equivale a aproximadamente 84 % do desempenho final usando 1 das 839 features. O classificador equivalente é um treshold simples: "se média de sílabas por palavra ≥ X, prediz LLM". A análise de correlação sinalizada confirma que LLMs usam palavras com **mais sílabas em média** (Pearson r = +0,691). O segundo lugar, `nilc__flesch`, atinge F1 = 0,8337 com correlação negativa de −0,683 — humanos escrevem textos com Flesch (legibilidade) mais alta, isto é, mais simples. Essas duas features sozinhas, embora altamente correlacionadas entre si, esboçam o sinal central: **LLMs em PT-BR produzem texto lexicalmente mais sofisticado e menos legível** que humanos no domínio jornalístico falso, e essa diferença é tão sistemática que basta uma feature para 84 % de acurácia.

A curva da busca incremental concretiza essa observação. Com k = 5 features, o SVM linear já atinge **F1 = 0,9035**; com k = 10, 0,9410; com k = 20, 0,9615; com k = 50, 0,9883; com k = 75 (pico), 0,9946. A inclinação da curva é íngreme no início e satura rapidamente — característica de problemas onde poucas features carregam quase todo o sinal. Concretamente, **as 10 primeiras features capturam 94 % do que o conjunto inteiro de 839 oferece**, e as 75 primeiras capturam praticamente tudo. Para o paper, isso permite duas afirmações: (i) o classificador é fortemente parsimonioso, e (ii) o **investimento de extração** (LIWC, NILC-Metrix completo, regras Enhanced UD com 32 819 entradas, etc.) é proporcionalmente baixo no retorno marginal — uma fração pequena dessas features faz quase todo o trabalho.

## 5. Vazamentos de tamanho confirmados quantitativamente

O diagnóstico **confirma e quantifica** os vazamentos que foram apontados qualitativamente em [RELATORIO_RESULTADOS.md §4](RELATORIO_RESULTADOS.md). Duas features do LIWC aparecem entre as top-10 do F1 univariado e são vazamentos diretos: `liwc__word_count` atinge F1 = 0,7915 sozinha (correlação Pearson +0,528 — LLMs têm word_count maior, como já sabemos), e `liwc__matched_words` atinge F1 = 0,7901 (correlação +0,513). Essas duas features são literais contadores de palavras (`word_count` = total de tokens; `matched_words` = tokens reconhecidos pelo dicionário LIWC) que escaparam do filtro Tier A porque o blacklist foi aplicado apenas ao loader NILC, não ao loader LIWC. **Corrigir esse vazamento é mudança de 3-4 linhas** no `load_liwc` em [linguistic_features.py:277-307](linguistic_features.py#L277): adicionar um drop de `word_count`, `matched_words` e `dictionary_coverage` análogo ao Tier A do NILC.

Outras features no top-20 do F1 univariado têm caráter ambíguo. `nilc__content_word_diversity` (F1 = 0,8152, corr +0,606) é uma medida tipo TTR — formalmente length-invariante mas empiricamente length-biased, exatamente o perfil das features que considerei para Tier B antes do usuário decidir não estendê-lo. `nilc__punctuation_diversity` (F1 = 0,7963, corr −0,563) e `nilc__ttr` (F1 = 0,7747) seguem a mesma lógica. `nilc__honore` (F1 = 0,8185, corr +0,607) é um índice de riqueza vocabular clássicamente reconhecido como length-biased na literatura de estilometria. Já `nilc__idade_aquisicao_mean` e `nilc__idade_aquisicao_1_25_ratio` (rank 9 e 11), bem como `nilc__imageabilidade_*` no top-20 da F-stat, são features psicolinguísticas que medem propriedades das palavras escolhidas — provavelmente sinal genuíno de estilo lexical, ainda que length-correlated em algum grau.

## 6. Sinal sintático genuíno detectado

Um achado importante é a presença da regra Enhanced UD `VERB(PUNCT/punct, *, NOUN/obj)` no **rank 12 do F1 univariado** (F1 = 0,7762, correlação Pearson +0,450) — a única regra ED entre as top-20, mas com poder discriminativo individual considerável. Essa regra captura padrão "vírgula como dependente à esquerda de um verbo que tem um substantivo como objeto à direita", isto é, construções como "*X, fez o lançamento Y*" ou "*Como dito acima, descreveu o evento*" — preferência sistemática de LLMs por inserir incisos pontuados antes do verbo principal. A correlação Pearson de +0,45 é mais moderada que as features lexicais do topo, o que **fortalece** a interpretação de sinal genuíno: essa regra não é proxy direto de tamanho, e mesmo assim discrimina humanos de LLMs com F1 univariado de 0,78. A regra `ud__ADJ(*)` aparece no rank 15 (F1 = 0,7655, corr +0,55) — adjetivos como tokens-folha são proporcionalmente mais frequentes em texto LLM, consistente com o achado de [RELATORIO_RESULTADOS.md] de que `adj` é a categoria LIWC mais característica de LLM. Essas duas regras sintáticas confirmam que o pipeline Enhanced UD está capturando sinal real, ainda que diluído entre 500 regras das quais 480 são pouco informativas individualmente.

## 7. Distribuição do top-20 por grupo de features

Considerando o top-20 do F1 univariado, **15 features são do NILC-Metrix**, 2 são do LIWC (`word_count` e `matched_words`, ambas vazamentos), 2 são regras Enhanced UD (`VERB(PUNCT/punct, *, NOUN/obj)` e `ADJ(*)`), 1 é do POS tagger (`pos__ADJ` — contagem de adjetivos) e 1 é do contador de sílabas (`syll__media_silabas_por_palavra`, que é a #1 absoluta). **Nenhum termo SAGE** aparece no top-20, e como o `parser_stats` retornou vazio, esse grupo está fora completamente. Esse desbalanceamento — 75 % das features do topo vindas do NILC-Metrix — sugere que, em caso de cortes de escopo para o paper, **o NILC-Metrix é o componente menos descartável** do "pacotão", seguido pelo Enhanced UD e o contador de sílabas. LIWC e SAGE, embora úteis para análises qualitativas, têm contribuição marginal pequena além do vazamento de `word_count`.

## 8. Recomendações operacionais

Quatro ações concretas decorrem do diagnóstico. **Primeira**: corrigir o vazamento do LIWC removendo `word_count`, `matched_words` e `dictionary_coverage` do output do `load_liwc`. Sem isso, qualquer número reportado no paper carrega esse viés direto. **Segunda**: para a tabela principal do paper, reportar o experimento com **k = 75 features apenas**, ordenadas pelo F1 univariado (já listadas no JSON em [results/feature_diagnostic.json](results/feature_diagnostic.json)) — isso atinge F1 = 0,9946 que é o teto natural do sinal linguístico, é defensável metodologicamente, e fornece uma tabela curta e interpretável de "as 75 features que importam". **Terceira**: incluir no paper a comparação explícita "linguístico só (F1 = 0,9946) vs combined com BERT (F1 = 1,0000)" como evidência de que cada bloco contribui com algo distinto — o linguístico fornece a estrutura discriminativa interpretável, o BERT fornece o ajuste fino. **Quarta**: reportar o F1 univariado de `syll__media_silabas_por_palavra` (0,8404) como linha de base trivial — qualquer baseline simples que pretenda ser publicável precisa explicitamente bater esse número, e ele é tão alto que serve de termômetro para a dificuldade real do problema no corpus deste estudo.

Quanto à decisão sobre Tier B ampliado, este diagnóstico **enfraquece** o argumento de que ele é estritamente necessário: mesmo com TTR, Honoré, Brunet, diversidades e LSA stds no pacotão, o F1 satura em 0,9946 — não em 1,0. Removendo essas ~44 features Tier B, o teto provavelmente desceria para algo entre 0,97 e 0,99, mas as conclusões interpretativas (LLMs usam palavras maiores, menos legíveis, com construções `VERB(PUNCT, *, NOUN)`) sobreviveriam. A decisão é mais sobre quanto enxugar a apresentação do que sobre integridade científica. **Recomendo manter Tier A apenas** (decisão atual), corrigir o vazamento LIWC, e relatar honestamente no paper que o conjunto contém features length-correlated cuja contribuição foi caracterizada — em vez de tentar removê-las e acabar removendo sinal junto.
